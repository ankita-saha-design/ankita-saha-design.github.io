Visual Design System

A visual design system for the Juspay dashboard, the control room of a platform processing over 300 million transactions a day. It spans a four-style icon library, a state illustration set with color reserved for meaning, and illustrated thumbnails for the feature catalog.

One language, three layers

The dashboard where merchants run their payments needed visuals that stay calm around dense data and still guide every decision.
